## 🗺️ Beginner Roadmap

If you are just starting out, follow this step-by-step order:

```
Step 1 → Learn a Programming Language (C++ / Java / Python)
Step 2 → Learn Data Structures & Algorithms (DSA)
Step 3 → Study CS Core Subjects (OS, DBMS, CN, OOP)
Step 4 → Learn Full-Stack Web Development (MERN)
Step 5 → Learn Design Patterns
Step 6 → Learn Low-Level Design (LLD)
Step 7 → Learn High-Level Design (HLD / System Design)
Step 8 → Practice Competitive Programming (optional)
Step 9 → Build Real Projects
Step 10 → Prepare Resume & Start Applying
```

---

## ⭐ Recommendations

- ✅ Stay consistent — daily practice matters more than intensity
- ✅ Practice DSA every day without skipping
- ✅ Build projects while learning, not after
- ✅ Participate in coding contests regularly
- ✅ Push your code to GitHub consistently
- ✅ Learn by building, not just watching videos
- ✅ Focus on depth rather than collecting resources
